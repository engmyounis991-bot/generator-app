# تطبيق إدارة اشتراكات المولدة — نسخة مبدئية (MVP)

تطبيق Flutter لإدارة مشتركي خطوط المولدة، يعمل على أندرويد (ولاحقاً آيفون من نفس الكود).

## الميزات في هذه النسخة
- إضافة / تعديل / حذف مشترك.
- الحقول: الاسم، الهاتف، فئة الاشتراك (عادي/ذهبي)، سعر الأمبير، عدد الأمبيرات، الواصل، ديون سابقة، رقم الكابينة، رقم الجوزة، تاريخ الانتهاء، ملاحظات.
- **حسابات تلقائية**: مبلغ الاشتراك = سعر الأمبير × عدد الأمبيرات، المتبقي، ومجموع الديون.
- **بحث** بالاسم/الهاتف/الكابينة.
- **شاشة رئيسية** فيها عدد المشتركين ومجموع الديون.
- **إرسال الوصل عبر واتساب بضغطة واحدة** (يفتح محادثة المشترك مع الوصل جاهزاً).
- تخزين محلي بقاعدة SQLite (يعمل بدون إنترنت).

## خطوات التشغيل
المشروع يحتوي على ملفات الكود فقط (`lib/` و `pubspec.yaml`). لتوليد مجلدات أندرويد/آيفون:

```bash
# 1) ثبّت Flutter SDK و Android Studio أولاً
cd generator_subscribers

# 2) ولّد مجلدات المنصّات (android / ios)
flutter create .

# 3) نزّل الحزم
flutter pub get

# 4) شغّل على جهاز/محاكي متصل
flutter run
```

### بناء ملف APK للتثبيت والمشاركة
```bash
flutter build apk --release
```
الملف يطلع هنا: `build/app/outputs/flutter-apk/app-release.apk`
تقدر تنقله للموبايل وتثبّته مباشرة (بدون متجر بلاي).

## مهم: تفعيل فتح واتساب على أندرويد 11+
بعد `flutter create .`، افتح ملف:
`android/app/src/main/AndroidManifest.xml`
وأضف هذا المقطع **داخل** وسم `<manifest>` وقبل وسم `<application>`:

```xml
<queries>
  <intent>
    <action android:name="android.intent.action.VIEW" />
    <data android:scheme="https" />
  </intent>
</queries>
```
بدون هذا المقطع قد لا يفتح واتساب على بعض الإصدارات الحديثة.

## كيف أحصل على ملف APK الجاهز للتثبيت؟
الـ APK لا يأتي مع الكود — يجب بناؤه. اختر أسهل طريقة لك:

### الطريقة 1: بناء تلقائي عبر GitHub (بدون تثبيت أي شيء على جهازك)
1. أنشئ حساب على github.com ومستودعاً (repository) جديداً.
2. ارفع محتويات هذا المشروع إليه (المشروع يحتوي أصلاً على ملف الأتمتة `.github/workflows/build-apk.yml`).
3. ادخل تبويب **Actions** في المستودع — سيبدأ البناء تلقائياً.
4. بعد انتهائه، افتح آخر تشغيل وحمّل ملف **app-release-apk** من قسم Artifacts. هذا هو ملف التثبيت.

### الطريقة 2: بيئة Flutter أونلاين
ارفع المشروع إلى موقع مثل FlutLab.io واطلب Build APK من داخله، ثم حمّل الناتج.

### الطريقة 3: على جهازك (Android Studio)
نفّذ الأوامر في قسم "خطوات التشغيل" أعلاه، ثم:
```bash
flutter build apk --release
```
الملف يطلع في: `build/app/outputs/flutter-apk/app-release.apk`
